#### 运动

##### 寻找设备

```cmd
#端口
lerobot-find-port

#相机
lerobot-find-cameras opencv
```

##### 操纵

```cmd
lerobot-teleoperate 
    --robot.type=so100_follower 
    --robot.port=COM6 
    --robot.id=follower_arm1 
    --teleop.type=so100_leader 
    --teleop.port=COM5 
    --teleop.id=leader_arm1 
    --display_data=false 
    --robot.cameras="{robot1: {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30}, overall: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}}"
```

#### 装配

##### 寻找port

```cmd
lerobot-find-port
```

##### 设置电机

```cmd
# leader
lerobot-setup-motors ^
    --teleop.type=so100_leader ^
    --teleop.port=COM3
```

```cmd
# follower
lerobot-setup-motors ^
    --robot.type=so100_follower ^
    --robot.port=COM3
```
